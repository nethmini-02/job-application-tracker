# Job Application Tracker

Simulated SDLC project: a web app for tracking job applications (Applied, Interview, Offer, Rejected).

## Tools
- Jira: sprint planning, backlog, bug tracking
- GitHub: version control and releases
- GitHub Actions: CI pipeline

## Branch Strategy
- `main`: production-ready code
- `develop`: integration branch
- `feature/JAT-x-name`: one branch per ticket

## Commit Convention
Every commit starts with the Jira ticket key, e.g. `JAT-12 Add initial index.html`.
